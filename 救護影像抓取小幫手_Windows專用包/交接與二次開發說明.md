# 救護影像抓取小幫手 - 系統交接與二次開發說明文件

本文件專為後續接手維護、功能擴充或修改程式之工程師／同仁編寫。

---

## 一、 快速總覽

* **程式語言**：Python 3 (相容 Python 3.8 ~ 3.12+)
* **GUI 框架**：Tkinter（Python 原生內建，無需額外安裝 GUI 庫）
* **第三方套件依賴**：**完全零依賴 (Zero External Dependencies)**！
  * Excel 勤務表（`.xlsm` / `.xlsx`）解析完全使用純 Python 標準庫 `zipfile` + `xml.etree.ElementTree` 開發，無需安裝 `openpyxl` 或 `pandas`。
  * 只要電腦有安裝官方標準 Python，開箱即跑。
  * 唯一的選用套件為 `pyinstaller`（僅在需要編譯打包成 Windows 獨立 `.exe` 檔時才需安裝）。

## 三、 `video_backup.py` 程式架構地圖

若要修改特定功能，請直接在 [`video_backup.py`](video_backup.py) 搜尋以下關鍵函式：

1. **勤務表 Excel 解析核心 (Excel Parser)**
   * `parse_roster_excel(file_path)`：純 XML 串流解析 `.xlsm`，讀取 C18:Z24 名冊矩陣與救護班排班。
   * `find_latest_roster_file(folder_path)`：依日期碼（如 1002）與檔案更新時間自動比對當月排班檔。
   * `get_on_duty_officers(...)`：處理消防 08:00~隔日 08:00 勤務日切換邏輯，精準取出該出勤時段人員。

2. **介面繪製與欄位連動 (UI Layout & Widgets)**
   * `setup_officer_combobox(...)`：同仁姓名下拉選單。已實作 `postcommand` 保證展開全體 20 位同仁，並保留鍵盤輸入即時搜尋功能。
   * `swap_bodycam(...)` / `cycle_bodycam_roster(...)`：密錄器 1、2、3 人員互換與三向輪替邏輯。
   * `create_task_tab(...)`：各任務分頁配置（案號、出勤時段、行車紀錄器與密錄器區塊）。
   * `add_task_tab(...)`：頂端 `[ ➕ ]` 新增多工分頁，案號自動連動分頁標籤。

3. **記憶卡與磁碟自動偵測 (Drive Detection)**
   * `find_drive_by_label(...)` / `find_dashcam_and_bodycams(...)`：根據磁碟名稱標籤或預設路徑自動掛載來源端。

4. **預檢確認對話框 (Precheck & Dialogs)**
   * `show_precheck_dialog(...)`：點擊「🚀 開始比對並複製」後的彈出預檢視窗，顯示各設備檔案數、大小、預估時間，並提供缺影空資料夾勾選與原因下拉選單。

5. **多線程背景傳輸與兩階段換卡機制 (Worker & File Copy)**
   * `start_backup_worker(...)`：背景工作線程，執行檔案過濾、目錄自動建立（`[案號][姓名]` 等規範格式）。
   * **共用讀卡機換卡邏輯**：當偵測到密錄器共用相同路徑或讀卡機時，第一階段傳輸完畢自動彈窗提示「請拔出更換第二張記憶卡」，確認後自動接續傳輸。

6. **【快速設定】分頁 (Settings Tab)**
   * `create_settings_tab(...)`：提供選擇當月排班資料夾／排班檔案、即時測試解析、儲存標籤與自訂缺影原因清單。

## 四、 開發環境建置與測試

### 1. 本地開發測試
只要有安裝 Python 3 即可直接執行：
```bash
python video_backup.py
```
*(在 Windows 上若要測試無黑屏版，可執行 `pythonw video_backup.pyw`)*

### 2. 修改後的關鍵注意事項
1. **檔案編碼格式**：
   * 編輯程式碼時，編輯器（如 VS Code、Cursor）務必使用 **UTF-8** 編碼儲存，以保留介面中的 Emoji 圖示與繁體中文提示。
2. **同步更新 `.pyw`**：
   * 修改完 `video_backup.py` 後，記得複製一份覆蓋 `video_backup.pyw`，確保 Windows 使用者體驗一致。
3. **編譯打包成單一 EXE 檔（可選）**：
   * 在有網路的 Windows 環境安裝 PyInstaller：
     ```bash
     pip install pyinstaller
     ```
   * 執行打包腳本：
     ```bash
     python build_exe.py
     ```
   * 打包完成後，獨立執行的 EXE 會生成在 `dist/` 目錄中。
