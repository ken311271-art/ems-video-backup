# 救護影像抓取小幫手 (v4.0 簡易操作版)

專為第一線消防救護同仁設計的救護影像自動化備份歸檔工具。具備 17 碼派遣案號嚴格防呆、直式清晰排版（民國年份 3 碼／月份日期 4 碼）、當月勤務表自動排班對應、設備防插錯雙重驗證、共用讀卡機換卡防呆、未錄影空資料夾自動規範建立、最左側多任務分頁標籤、以及 1/2/3 號密錄器單鍵姓名互換。

---

## 🚀 平常救護返隊：簡單 3 動搞定 (90% 常態)

1. **第 ❶ 動：輸入 17 碼案號與出勤時段（直式排列清晰好讀）**
   * **案件案號**：輸入 17 碼完整派遣案號（例：`1131023-01`），右側具備即時字數檢查提示（未滿 17 碼或超標會即時以紅字提醒，達標自動亮綠燈）。
   * **出勤年份 (民國 3 碼)**：例 `113`（西元 2024 年為 113）。
   * **月份日期 (4 碼 MMDD)**：例 `1023`（表示 10 月 23 日）。
   * **出勤時間 (4 碼 HHMM)**：24 小時制，預設為**當下時間往前推算 1 小時**（例 `0930`）。
   * **返隊時間 (選填 4 碼)**：平時可留空白，系統會自動抓到出勤後最新影片。

2. **第 ❷ 動：插隨身碟 ➔ 點【⚡ 刷新連線並讀取排班】**
   * 系統自動依序執行：**先清空舊人員姓名 ➔ 重新偵測各設備隨身碟連線 ➔ 依出勤時段自動帶入救護班同仁**！
   * **嚴格硬體授權原則**：系統完全依據「插入並連線的設備」開放填寫；若排班表人數大於連線設備數（例如排班 3 人但只插 2 部密錄器），只會填入有連線的設備，未連線者保持鎖定（disabled）與空白，絕不誤填！
   * **司機與救護員對調？** 點一下 `[ ⇅ 1 ⇄ 2 號 ]` 秒對調！
   * **三人出勤（實習生／義消）？** 點 `[ 🔓 手動解鎖 ]` 開放 3 號位，或點 `[ ⇅ 2 ⇄ 3 號 ]` / `[ 🔄 1➔2➔3 輪替 ]` 快速對調。
   * **手動換人或選其他人？** 點欄位右側 `▼` 倒三角下拉（全員名單都在），或在欄位直接打名字任一字即時篩選。

3. **第 ❸ 動：點【🚀 開始比對並自動複製】（緊接在步驟 ❷ 下方，路徑設定上方）**
   * 步驟 ❶、❷、❸ 集中於主畫面最上方，流程一氣呵成！
   * 畫面彈出【預檢確認視窗】，快速瞄一眼各設備部數，點擊「確定開始複製」，背景即以最高速多線程完成備份！下方常設路徑設定平時自動鎖定，出勤作業完全免接觸。

## 📌 Windows 版本專屬：最小化自動縮小至右下角系統匣 (通知區域)

* **按縮小不佔工作列**：在 Windows 系統中，點擊視窗右上角「縮小 (—)」按鈕，程式會自動縮小隱藏至桌面右下角工作列系統匣 (通知區域)，完全不佔用工作列空間。
* **背景備份不中斷**：複製中的任務持續在背景以最高速多線程執行，當複製完成時，右下角會自動彈出「🎉 備份完成」氣球吐司通知提醒出勤同仁！
* **一鍵即時還原**：點擊或雙擊右下角小幫手圖示，即可立即將主視窗還原至最上層；亦可對圖示按滑鼠右鍵，選擇「🖥️ 開啟主視窗」或「❌ 結束程式」。
* **防重複開啟（單一執行個體喚醒）**：若程式已在執行中（無論在右下角縮小常駐或是一般視窗），再次雙擊啟動程式時，系統**絕不重複開啟新進程**，而是直接將已開啟的視窗**秒還原並切換至最前景**！
* **純原生 API**：使用純 Windows Win32 API (`ctypes`) 實作，公務機免安裝任何額外套件，即點即用！

## 🔄 全自動軟體更新功能 (放置新檔即自動升級)

* **零操作無痛升級**：在【⚙️ 快速設定】分頁中指定「自動更新來源資料夾」（可指定為分隊 NAS 共用槽、公用隨身碟或個人「下載」資料夾）。
* **免改檔名、自動辨識**：只要將更新檔放入該資料夾，程式自動挑選最新修改時間之檔案。支援：
  1. 獨立程式檔：`video_backup.pyw`、`video_backup_v4.2.pyw`、甚至重複下載的 `video_backup (1).pyw`。
  2. 專用包壓縮檔：`救護影像抓取小幫手_Windows專用包.zip`（程式自動解析內部最新檔案）。
* **智慧偵測與安全重啟**：
  * **啟動自動偵測**：程式啟動時在背景自動檢查，若有新版本主動彈窗提示是否升級並自動重啟。
  * **隨時手動檢查**：亦可在設定分頁隨時點擊【🔄 立即檢查更新】。
  * **既有設定完整保留**：更新時舊檔自動備份為 `.bak`，原本已設定之各項路徑（`backup_config.json`）100% 完整保留！

## ⚡ 共用讀卡機（行車紀錄器 ＆ 密錄器 3）專利防呆

當行車紀錄器與密錄器 3 共用同一讀卡槽（如同一磁碟代號 `E:\`）時：

1. **情境 A：插行車紀錄器卡片（90% 日常常態）**
   * 行車紀錄器顯示 `🟢 已連線`；密錄器 3 顯示 `⚪ 未連線 (共用槽)` 且**自動鎖定（disabled）**。
   * **無第 3 人（常見 2 人出勤，未填密錄 3 姓名）**：行車與密錄 1、2 複製跑完即圓滿結束，**完全不跳換卡提醒！**
   * **有第 3 人（手動解鎖並 Key 姓名）**：行車複製完畢後，系統**自動跳出換卡提醒視窗**，拔下行車卡換插密錄 3 繼續複製。

2. **情境 B：只插密錄器 3 卡片**
   * 密錄器 3 顯示 `🟢 已連線`；行車紀錄器顯示 `⚪ 未連線 (共用槽)`，且旁邊自動出現 **`☑ 本次需換卡複製行車紀錄器`（預設勾選）**。
   * **維持勾選（預設）**：密錄 3 複製完畢後，系統**跳出換卡提醒換插行車卡**繼續複製。
   * **取消勾選（本次只需密錄 3）**：密錄 3 跑完直接結束，**完全不跳換卡！**

3. **背景拷貝不中斷**：換卡提醒視窗彈出時，**密錄器 1 與 2 仍於背景全速拷貝中**，換卡完全不中斷其他設備！

## 💡 常見特殊狀況排除（秒解小抄）

* **設備沒開機／沒錄到（0 部影片）？**
  * 在預檢確認視窗中，直接勾選「建立空資料夾並備註原因」，並於下拉選單秒選原因（如：`設備沒電`、`未開機`）。
  * 系統會自動建立規範資料夾並產出 `說明.txt`，省去手動寫說明的麻煩！
* **換新月份勤務表 / 初次設定？**
  * 切換到最右側【⚙️ 快速設定】分頁，點擊「📄 選擇檔案」選取當天排班 Excel（或點「📁 選擇資料夾」指定當月目錄）。
  * 載入後系統會立即彈出成功訊息，並同步刷新所有分頁選單！
* **同時處理多件救護（多分頁多工）？**
  * 點擊分頁列最左側的 **`[ ➕ ]`** 即可開立新任務分頁，不同案件各自獨立備份。
  * 若剛出勤結束想終止，點「⛔ 暫停並放棄」會自動安全清理已建立檔案，不留垃圾。
* **螢幕解析度較小或筆電畫面顯示不全？**
  * 軟體具備平滑滾輪捲動容器，在視窗任何位置滑動滑鼠滾輪即可順暢上下捲動，保證所有設定一覽無遺；亦可隨時點擊視窗最大化或自由拉大。

## 💻 啟動方式與【極速秒開指南】

* **🪟 Windows 公務機 (推薦 2 種極速秒開方式)**：
  1. **首選極速法 (0.3 秒無感秒開)**：直接點兩下 **`啟動影像備份(無黑屏).vbs`**（電腦有安裝 Python 時，純腳本背景秒開，無黑黑的 CMD 視窗）。
  2. **免安裝 Python 的公務機**：執行 `在Windows一鍵打包成EXE.bat`，選擇 `[1] 極速啟動版 (目錄模式)`。產生之資料夾內的 `救護影像抓取小幫手.exe` 已經預先解壓所有函式庫，**1 秒內極速啟動**，完全避開防毒軟體重複掃描！
  3. *(傳統單一 EXE 檔為何較慢？因為 Windows 每次打開單一 EXE 都必須將所有元件解壓縮到暫存資料夾，加上公務機防毒軟體即時攔截掃描，才會耗時 5~15 秒)*

* **🍏 Mac 電腦**：
  1. **命令稿啟動 (0.2 秒秒開)**：直接點兩下 **`啟動影像備份.command`** 即可極速啟動。
  2. **獨立 App 啟動**：若打開 `救護影像抓取小幫手.app` 時 Dock 圖示跳動較久，可於終端機執行 `xattr -cr "救護影像抓取小幫手.app"` 清除 macOS Gatekeeper 隔離檢驗標記，即可恢復秒開！
