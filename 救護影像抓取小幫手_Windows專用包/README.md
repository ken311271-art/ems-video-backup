# 救護影像抓取小幫手 (v3.9 簡易操作版)

專為第一線消防救護同仁設計的救護影像自動化備份歸檔工具。具備當月勤務表自動排班對應、設備防插錯雙重驗證、共用讀卡機換卡防呆、未錄影空資料夾自動規範建立、以及 1/2/3 號密錄器單鍵姓名互換。

---

## 🚀 平常救護返隊：簡單 3 動搞定 (90% 常態)

1. **第 ❶ 動：輸入案號與時間**
   * 輸入【案件案號】（例：`1131022-01`）與【出勤時間】（4碼24小時制，例：`1900`）。
   * *返隊時間平時可留空白，系統會自動抓到出勤後最新影片；今日目錄代碼會自動對應（如 `[1022]`）。*

2. **第 ❷ 動：插隨身碟 ➔ 點【⚡ 快速讀取排班】**
   * 系統自動比對當天勤務表，將救護班同仁依序自動帶入密錄器 1、2。
   * **司機與救護員對調？** 點一下 `[ ⇅ 1 ⇄ 2 號 ]` 秒對調！
   * **三人出勤（實習生／義消）？** 點 `[ ⇅ 2 ⇄ 3 號 ]` 或 `[ 🔄 1➔2➔3 輪替 ]`，自動解鎖 3 號位。
   * **手動換人或選其他人？** 點欄位右側 `▼` 倒三角下拉（全員名單都在），或在欄位直接打名字任一字即時篩選。

3. **第 ❸ 動：點【🚀 開始比對並自動複製】**
   * 畫面彈出【預檢確認視窗】，快速瞄一眼各設備部數，點擊「確定開始複製」，背景即以最高速多線程完成備份！

---

## 💡 常見特殊狀況排除（秒解小抄）

* **設備沒開機／沒錄到（0 部影片）？**
  * 在預檢確認視窗中，直接勾選「建立空資料夾並備註原因」，並於下拉選單秒選原因（如：`設備沒電`、`未開機`）。
  * 系統會自動建立規範資料夾並產出 `說明.txt`，省去手動寫說明的麻煩！
* **行車紀錄器與密錄器 3 共用讀卡機 (E:\)？**
  * 先插行車卡，點開始複製。行車紀錄器拷貝完畢時，畫面會跳出「換卡提示」，此時拔出換插密錄 3 即可。（密錄器 1、2 在背景全速複製，換卡過程完全不中斷！）
* **換新月份勤務表 / 初次設定？**
  * 切換到右側【⚙️ 快速設定】分頁，點擊「📄 選擇檔案」選取當天排班 Excel（或點「📁 選擇資料夾」指定當月目錄）。
  * 載入後系統會立即彈出成功訊息，並同步刷新所有分頁選單！
* **同時處理多件救護（多分頁多工）？**
  * 點擊上方分頁列的 `[ ➕ ]` 即可開立新任務分頁，不同案件各自獨立備份。
  * 若剛出勤結束想終止，點「⛔ 暫停並放棄」會自動安全清理已建立檔案，不留垃圾。

## 📁 自動建立之規範目錄格式

* **行車紀錄器**：
  `【行車紀錄器存放目錄】 / [MMDD] / [案號] / (所有該時段影片)`
  *(若無錄影並備註原因：`[案號](原因)` 內附 `說明.txt`)*
* **密錄器影像**：
  `【密錄器存放目錄】 / [MMDD] / [案號] / [案號][同仁姓名] / (所有該時段影片)` *(嚴格禁止底線)*
  *(若無錄影並備註原因：`[案號][同仁姓名](原因)` 內附 `說明.txt`)*

## 💻 啟動方式

* **🪟 Windows 公務機**：
  解壓縮 `救護影像抓取小幫手_Windows專用包.zip`，直接點兩下 **`啟動影像備份(無黑屏).vbs`** 或 **`啟動影像備份.bat`**。
* **🍏 Mac 電腦**：
  直接點兩下執行 **`啟動影像備份.command`** 即可啟動。
